# Ticket font

Unmodified Noto Sans Arabic variable font, bundled locally under SIL OFL 1.1 (see OFL.txt). Source: https://github.com/google/fonts/tree/main/ofl/notosansarabic . Used with @pdf-lib/fontkit for Arabic shaping and supported Latin text. No runtime font download is required. Scripts absent from the font are rejected explicitly, never silently rendered as missing-glyph boxes.

SHA-256 of bundled font: `63111b5b2e074dd48cc67692e0a2726d86ee94c1c37fe8598257b7b4e87e869e`.
